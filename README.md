# AI 副业变现自检器

输入你的技能、可投入时间、启动资金，AI 从变现路径、回本周期、可复制性三维打分，给出一个适合你的副业方向清单和起步三步。不荐项目、不承诺收益、不卖课。

## 它能帮你做什么

- 理清你手上有什么：技能、时间、资金、人脉
- 匹配适合的变现类型：内容创作、智能体代搭建、信息差变现、自动化套利
- 三维打分：现金流快 + 可复制 + 回本周期短，排出优先级
- 给起步三步：选切口 → 做最小验证 → 放量
- 提醒常见坑：别一上来买课、别碰万能型、别忽视交付

## 怎么用

1. 告诉它你的基本情况（会什么、每天几小时、能拿出多少启动金）
2. 说明你想做的方向，或完全交给它推荐
3. 拿到一份带优先级的变现自检清单和下一步动作

## 适合谁

- 想搞副业变现但不知道从哪下手的普通人
- 有一技之长、想用 AI 把时间变成 1 对 N 的自由职业者
- 想做一人企业、用智能体顶一个团队的小老板

## 合规边界

- 不荐具体项目、不承诺收益、不卖课
- 不引导加微信、不绑定私域
- 所有建议仅作思路参考，决策与风险自行承担
